## 2. Architecture in one screen (details: [docs/LOCALE.md](docs/LOCALE.md))

- **Overlay tables** `public/locales/en/<data file>.json` = `{ locale, strings: { <exact Chinese text>: <English> }, reviewed: { <zh>: <why it may differ in tags / numbers> } }`.
  `public/js/locale.js` (`applyLocale`, `TEXT_KEYS`) is applied by the browser's data store (`public/js/data.js`) at read time;
  a text without an entry stays Chinese (so a stale table never breaks the game), `?lang=zh` turns it off. A plain `desc` that
  mirrors a markup `descRaw` is derived from the translated `descRaw` (`richTextPlain`), so a table holds only the markup text.
- **The simulation and the server read the pristine Chinese `data/*.json`** (they parse Chinese rule text with regexes). Text the
  server *composes* from the data reaches clients through `L()` in `server/display.js` (wire boundary only; `SP_LOCALE=zh` turns it
  off). Texts that exist only on the wire (multi-round bounty cards: `bountyText` in `server/match/choices.js`) are *derived
  sources*: ordinary table keys listed by `derivedSources()` in `tools/locale.mjs`.
- **UI chrome** (`public/js/**`, `public/css/**`, `shared/constants.js`) and the server's fixed messages are English in place.
  Emote labels: `public/js/ui/emoteText.js`.
- **Checks:** `tools/locale.mjs` — `coverage [--list] [--files a,b] [--strict a]`, `check [--terms]`, `sync [--write]`,
  `harvest [--write] [--refresh] [--overwrite]` (official Global English from `en_US`). `checkEntry` rejects an entry whose tags,
  placeholders, digits, line breaks or `<condition>` markers differ from the source, that still contains Chinese, or that no
  display field has any more; differences that are correct (a number the source spells in Chinese and the English writes in
  words) go under `reviewed` with the reason.
- **Tests that pin the localization:** `test/locale.test.js` (mechanism, shipped tables, coverage ratchet, official operator names),
  `test/display.test.js` (`L()`, derived texts, and the wire test: bot matches played to the result send no Chinese display text).

[tools/locale-work/README.md](tools/locale-work/README.md) documents the scripts: reference dictionaries (`official-names.mjs`,
`doc-names.mjs`), batch building (`build-batches.mjs`), bounty-sentence generator (`gen-bounty.mjs`), `check-batch.mjs`,
`merge-batch.mjs`, `name-consistency.mjs`, reviewer input / fixes, the wire audit and the screenshot tours. The workflow that produced
the tables: *batch of missing texts (with context and reference names) → translation as `{ zh: en }` → `check-batch` → `merge-batch --write`
→ `sync --write` → `check` → commit*. For a data rebuild: `node tools/build-data.mjs`, `coverage --list`, `harvest --write`, translate the rest.

Gate before every commit: `check` clean, the two locale test files green, and — before a push — the whole suite.

## 7. Gotchas (lessons of this session)

- **Subagents:** more than ~3 concurrent agents exhausted the account's usage limit; agents die with HTTP 429 mid-run and the session can
  stall until the user returns. Keep ≤ 3 running, tell each to write its output file early and incrementally (partial outputs were salvaged
  twice), and zip translations by order (`[zh…]` ↔ `[en…]`) with a count check rather than copying keys.
- **`sleep` is blocked in the foreground.** Start long jobs with `run_in_background` and wait with an `until` loop in a second
  background command. Always pass an *absolute* output prefix to `run-tests.sh` (a relative one wrote logs into the repo once).
- **Tables are canonical:** key order = data order, then derived sources. Always write through `readTable` / `writeTable`
  (`tools/locale.mjs`); a hand-edited, re-ordered file fails `test/locale.test.js`.
- **A test that needs an English name** must read it the way production does: `L()` from `server/display.js`, or a fake `fetch` that serves
  `/locales/` to the browser data store. Do not hard-code a Chinese data name in an assertion about displayed text, and do not
  translate an identifier to make a test pass.
- **`tools/locale.mjs check` is strict about digits:** the English must contain every number of the source (and not extra ones
  unless listed under `reviewed`). `15％` (full-width) in a source is a `%`. Some sources end with `\r\n`; keep it.
- **GitHub:** the earlier `git push` 403 (Claude GitHub App not authorised) went away; if it returns, the user must install /
  authorise the app (https://github.com/apps/claude/installations/select_target or reconnect GitHub in claude.ai settings). As a
  fallback, `git bundle create /tmp/loc.bundle claude/sweet-archimedes-aqioeq` and hand the bundle over.
- `docs/DESIGN.md`, `SIM.md`, `META.md`, `DATA.md`, `CHANGELOG.md` and `docs/research/*` stay Chinese on purpose (internal engine docs and a raw
  data mirror, see `CHANGES.md` §5).
